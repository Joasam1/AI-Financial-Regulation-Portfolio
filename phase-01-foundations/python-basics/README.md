# Python Foundations — Evidence Stream

**Status:** Active

This module converts Python study into small, inspectable artifacts using a banking-supervision context.

## Exercise 01 — Prudential Indicator Summary

The first exercise uses a tiny **synthetic** bank dataset to practise:

- Python lists and dictionaries;
- functions and type hints;
- iteration and conditional logic;
- validation;
- calculation of simple portfolio indicators; and
- separating computation from interpretation.

The starter implementation is intentionally small. It is not evidence of independent mastery merely because it exists in the repository. The learning evidence is completed when the code is run, understood, modified, tested, and reflected on in the learning log.

## Run

```bash
python exercise_01_prudential_summary.py
```

## Validation tasks

Before marking this exercise complete:

1. Explain what each function does without relying on generated documentation.
2. Add at least one additional validation rule.
3. Add one additional calculated indicator.
4. Test an edge case.
5. Record what changed and what was learned in the learning log.
