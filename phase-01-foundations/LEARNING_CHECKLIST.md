# Phase 01 Learning Checklist

This checklist records evidence, not just course completion.

## Python and data analysis
- [ ] Python syntax, functions and core data structures demonstrated
- [ ] NumPy array operations demonstrated
- [ ] pandas loading, selection, filtering and transformation demonstrated
- [ ] Missing-data and duplicate handling demonstrated
- [ ] Grouping, aggregation and reshaping demonstrated
- [ ] Date/time and panel-style transformations demonstrated
- [ ] Reusable functions used instead of notebook-only repetition
- [ ] Data-quality assertions/checks included

## Statistics
- [ ] Descriptive statistics interpreted
- [ ] Probability/distribution concepts demonstrated
- [ ] Sampling and uncertainty documented
- [ ] Correlation distinguished from causation
- [ ] Linear/logistic regression foundations demonstrated
- [ ] Diagnostics and assumptions discussed

## Machine learning
- [ ] Problem framed as a prediction task
- [ ] Baseline established
- [ ] Train/validation/test logic demonstrated
- [ ] Preprocessing avoids data leakage
- [ ] At least two model families compared
- [ ] Appropriate classification/regression metrics used
- [ ] Calibration considered where probabilities are used
- [ ] Error analysis documented

## Reproducibility
- [ ] Environment/dependencies documented
- [ ] Random seeds used where relevant
- [ ] Public or synthetic data source documented
- [ ] Notebook/script can be rerun from clean inputs
- [ ] Limitations recorded
