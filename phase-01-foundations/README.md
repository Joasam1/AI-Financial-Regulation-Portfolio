# Phase 01 — Foundations

**Status:** Active

This phase builds the coding, data-analysis, statistical and machine-learning foundations needed for later work in AI × financial regulation.

## Objectives

1. Strengthen Python fluency for reproducible analytical work.
2. Demonstrate reliable data cleaning, transformation and exploratory analysis.
3. Implement core statistical and machine-learning concepts rather than only calling high-level tools.
4. Develop disciplined experiment and learning logs.
5. Produce confidentiality-safe evidence using public or synthetic data.

## Evidence sequence

### 1. Python & data analysis
Evidence will cover Python fundamentals, NumPy, pandas, data quality checks, transformation, aggregation and reproducible notebooks/scripts.

### 2. Statistical foundations
Evidence will cover distributions, sampling, estimation, correlation, regression, uncertainty and appropriate diagnostic thinking.

### 3. Machine-learning foundations
Evidence will cover supervised-learning workflow, preprocessing, leakage prevention, train/validation/test separation, baseline models and evaluation.

### 4. Financial-regulation application
Foundation concepts will be demonstrated through small banking/supervisory examples using public or synthetic data.

## Completion criteria

Phase 01 is not complete merely because courses or notebooks have been finished. Completion requires reproducible artifacts, a learning log, at least one end-to-end mini-project, documented evaluation and a reflection identifying remaining weaknesses.

## Current milestone

Begin with the Python/data-analysis evidence stream and connect formal learning directly to small reproducible implementations.
