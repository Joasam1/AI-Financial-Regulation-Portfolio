# Foundation Mini-Project — Banking Risk Analytics

**Status:** Planned

## Goal

Build a small, reproducible banking-risk analytics workflow using public or synthetic data. The purpose is to demonstrate foundational Python, statistics and machine-learning practice before advancing to the larger supervisory early-warning project.

## Intended workflow

1. Load and validate a panel-style dataset.
2. Perform data-quality checks and transformations.
3. Explore selected prudential indicators.
4. Define a transparent prediction target.
5. Establish a simple baseline.
6. Train introductory classification models.
7. Evaluate performance and errors.
8. Document limitations and supervisory interpretation.

## Important boundary

This mini-project is a learning artifact. It should not be represented as a production supervisory model or as evidence derived from confidential supervisory data.
